# BodyExpertX Therapist Android prototype

- Package ID: com.bodyexpertx.therapist
- Opens the existing therapist panel inside a native Android shell.
- Existing therapist panel and Supabase backend remain the source of truth.
- Current target: https://bodyexpertx-therapist.onrender.com

This is an early install-and-test prototype, not a Play Store release. A dedicated native push notification implementation with high-priority Android notifications, sound, vibration, and accept-job actions is a separate next phase; wrapping the current website alone does not guarantee Ola/Uber-style alerts when the app is backgrounded.
